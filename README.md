## Running the Project Locally

Because this is a front-end portfolio website, it does not require a backend server to run.

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project

Navigate into the project directory:

```bash
cd Tshepo-portfolio
```

### 3. Open the website

Open `index.html` in a web browser.

Alternatively, the project can be opened in Visual Studio Code and run using a local development extension such as Live Server.
